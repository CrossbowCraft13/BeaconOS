# Contributing to BeaconOS

First off, thank you for considering contributing to BeaconOS!

Our goal is to build the best operating system for Minecraft server hosting, and every contribution—whether it's code, documentation, testing, bug reports, or ideas—helps move the project forward.

## Ways to Contribute

You can help by:

* Reporting bugs
* Suggesting new features
* Improving documentation
* Fixing bugs
* Developing new features
* Testing releases
* Reviewing pull requests

## Getting Started

1. Fork the repository.
2. Create a new branch from `main`.
3. Make your changes.
4. Commit using clear commit messages.
5. Push your branch.
6. Open a Pull Request.

## Coding Standards

* Write clean and readable code.
* Comment complex logic when necessary.
* Keep functions focused and modular.
* Follow the existing project structure.

## Pull Requests

Please include:

* A clear description of your changes.
* Screenshots if UI changes are included.
* References to any related issues.

All pull requests will be reviewed before merging.

## Questions?

If you're unsure where to begin, look for issues labeled **good first issue** or start a discussion in the repository.

Thank you for helping build BeaconOS!
