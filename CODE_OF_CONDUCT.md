# BeaconOS Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, and inclusive environment for everyone.

## Expected Behavior

* Be respectful.
* Be constructive.
* Assume good intentions.
* Welcome newcomers.
* Provide helpful feedback.
* Focus on solving problems together.

## Unacceptable Behavior

* Harassment
* Personal attacks
* Hate speech
* Discrimination
* Trolling
* Spam
* Sharing malicious code

## Enforcement

Project maintainers reserve the right to remove comments, issues, pull requests, or contributors who violate this Code of Conduct.

Our goal is to create a community where anyone interested in Minecraft server hosting can learn, collaborate, and build something meaningful.
